# ユーザーテスト c2

実施日: 2026-11-10
対象の課題: obs-comment-skin-dxs.10

## はじめに

0.1.0 の公開の前に、依頼者が利用者の立場でドックを操作し、使い心地を確かめるテストです。合格の基準は、依頼者が全課題を補助なしで達成でき、依頼者が公開を妨げると判断した指摘が残っていないことです。

## 検証方法

手順書を渡す形ではなく、依頼者がポータブル版 OBS 33.0.1 でドックを操作しながら、気づいた点を会話で伝える形で行いました。開発のセッションは、指摘のたびに直してポータブル版 OBS を入れ替えました。

## 検証結果

依頼者は、最後の修正の後に「ユーザーテスト合格です」と判断しました。

テストの間に受けた指摘と対応は次のとおりです。

| 指摘 | 対応 | 記録 |
| --- | --- | --- |
| プルダウンなどの右端が見切れる | 中身の最小の幅を抑え、ドックの最小の幅を中身に合わせた | `2026-11-10-layout-check.md` |
| プレビューがスクロールバーにかぶる | プレビューをスクロール領域の外の上端に移した | 同上 |
| プレビューがプレビューであることが分からない | 見出しを付けた | 同上 |
| プレビューの上のほうが見切れる | 上端で一部しか見えないメッセージを隠し、プレビューの高さを変えられるようにした | 同上 |
| 文字を大きくしても見切れないか | 実物のアーカイブで調べ、Super Chat の金額と本文の切り取りを直した | 同上 |
| 「見本」を「プレビュー」にする。プレビューと自動の適用の説明文を削除する | 文言を変え、説明文を削除した | なし |
| 「名前の次の行に表示する」を「名前とコメント文の間に改行を入れる」にする | 項目名を変えた | なし |
| 配信者の名前の網掛けを透明にする方法が分からない | 網掛けを消す項目を足した | `2026-11-10-settings-gap-audit.md` |
| コメント欄の背景を透明にする方法が分からない | 背景色を選ばなくても不透明度が効くようにした | 同上 |
| 指摘した箇所以外の漏れも点検してほしい | 前提の無い欄を押せない状態にした。変える設定が無い見た目を洗い出した | 同上 |
| Super Chat と名前の書体が変わらない。書体は統一でよい | 書体を 1 つにまとめ、メッセージの中のすべての要素に当てた | 同上 |
| プレビューの背景を市松模様にする | 市松模様にした | 同上 |
| 「チャットへようこそ」や下部の「ログインしてチャットを始める」を消したい | 依頼者の決定で線引きを見直し、隠す項目を足した | 同上 |
| 数値はスライダーで設定したい | 数値と不透明度の欄をスライダーにした | なし |
| 上部の Super Chat の帯の項目が分からない | 項目名を「上部に並ぶ Super Chat のアイコンを表示する」にし、プレビューで帯を隠してもコメントの数が変わらないようにした | なし |

## 確認していないこと

- 書体が変わらなかった原因。計算済みのスタイルでは書体は当たっていた。依頼者が選んだ書体を聞いていないため、日本語の文字を含まない書体だったという推測を確かめていない。
- c2 の手順書に予定していた課題のうち、自分で書いた CSS が残ること、OBS の再起動の後に設定が戻ること、生成した CSS のコピーを依頼者が個別に試したこと。依頼者は全体として合格と判断した。開発のセッションは、これらを UI Automation と CDP で確かめている。

## 考察

手順書を渡す形より、操作しながら指摘を受けて直す形のほうが、見た目と言葉の分かりにくさを多く見つけられたと考えています。
