# 設定の漏れの点検

実施日: 2026-11-10

## 背景

依頼者がポータブル版 OBS でドックを操作し、配信者の名前の網掛けを透明にする方法と、コメント欄の背景を透明にする方法が分からないと報告した。依頼者は、指摘した箇所以外の漏れも点検するよう求めた。2 つの報告は、次の 2 種類の漏れだった。

- 他の設定を先に選ばないと効かない項目。全体の不透明度は、全体の背景色を選んだときだけ効いていた。
- YouTube の既定の見た目のうち、変える設定が無いもの。配信者の名前の網掛けを消す設定が無かった。

あわせて、依頼者は書体が変わらないと報告し、書体は部分ごとに指定させず統一でよいと決めた。

## 検証方法

- 1 種類目は、項目の表のすべての項目について、生成する CSS の条件を読み、他の項目の値に依存するものを書き出した。
- 2 種類目は、実物のページに全体の背景を透明にする規則を注入し、チャット欄の中で背景が透明でない要素を `tools/layout-check/opaque-scan.mjs` で一覧にした。対象は、依頼者の配信のチャットを表示する「ブラウザ」で、配信者の発言 1 件と YouTube の案内、下部のログインを促す欄があった。
- 書体は、Chrome で `https://www.youtube.com/watch?v=K6Po87_quEM` のチャット欄の iframe に `font-family: "Courier New"` の規則を注入し、名前・本文・Super Chat の名前・金額・本文の、テキストを直接持つ要素の計算済みの書体を読んだ。

## 検証結果

### 他の設定を先に選ばないと効かない項目

| 項目 | 前提 | 対応 |
| --- | --- | --- |
| 全体の不透明度 | 全体の背景色を選ぶ | 前提を外した。色を選んでいないときは YouTube の既定の背景色 `rgb(15, 15, 15)` に不透明度を掛ける |
| 縁の太さ、縁の色 | 文字を縁取るがオン | 前提を満たさない間は欄を押せない状態にする |
| アイコンの大きさ、形 | アイコンを表示するがオン | 同上 |
| 時刻の大きさ、色 | 時刻の表示が「表示する」。YouTube は時刻を既定で隠している | 同上 |
| メッセージの背景の不透明度、形 | メッセージ・配信者・モデレーター・メンバーのいずれかの背景色を選ぶ | 同上 |
| 現れる時間 | 浮かび上がらせるがオン、または現れる向きが「動かさない」以外 | 同上 |
| 消すまでの時間、消える時間 | 古いメッセージを消すがオン | 同上 |

欄を押せない状態にするのは、依頼者の指示でドックに説明の文を置かないため、効かない理由を欄の状態で伝えるためである。前提は項目の表に書き、単体テストで判定を確かめた。

### YouTube の既定の見た目のうち、変える設定が無いもの

全体の背景を透明にする規則を注入した後も塗られていた要素は次のとおり。

| 要素 | 背景色 | 対応 |
| --- | --- | --- |
| 配信者の名前 `#author-name.owner` | `rgb(241, 241, 241)` | 「配信者の名前を網掛けする」を足した。オフにすると網掛けを消し、色の指定が無ければ文字を黄色 `rgb(255, 214, 0)` にする。網掛けを消すと暗い文字が暗い背景に埋もれるため |
| 下部のログインを促す欄 `#input-panel` の子 | `rgb(15, 15, 15)` | 全体の背景色をこの欄にも当てる。欄そのものは隠さない |
| 「チャットへようこそ」の案内の枠 | `rgba(255, 255, 255, 0.1)` | 対応しない。隠す設定を置かないと決めた YouTube の案内である |
| 「ログインしてチャットを始める」のボタン | `rgba(255, 255, 255, 0.1)` | 対応しない。隠す設定を置かないと決めたリンクである |
| ボタンを押したときに光る層 7 つ | `rgb(255, 255, 255)` | 対応しない。祖先を含めた不透明度が 0 で、見えない |

修正の後に同じ検査を行うと、塗られて残る要素は、YouTube の案内の枠、ログインのボタン、光る層だけになった。

依頼者は「チャットへようこそ」と下部の欄の映り込みを気にした。いったんは規約のためとして、隠す設定を置かない方針を維持した。その後、隠せない理由が規約の明文ではなく、規約上もともとグレーな中で自主的に引いた線であることを説明すると、依頼者は線引きを見直すと決めた。

### 線引きの見直し

| 要素 | 見直しの後 |
| --- | --- |
| 上部の見出し (チャットのモード、トップファン、メニュー) | 隠せる。見直しの前から隠せた |
| 下部のログインの欄 `#input-panel` | 「下部のログインの欄を表示する」で隠せる |
| YouTube からの案内 `yt-live-chat-viewer-engagement-message-renderer` | 「YouTube からの案内を表示する」で隠せる |
| 商品の紹介、`div#promo`、バナー、固定のメッセージ、メッセージの中のリンク | 隠す設定を置かない |

実物のページに 2 つの規則を当てると、下部の欄と案内の `display` が `none` になり、チャットの一覧の下端が 507 px から 599 px に下がって、チャット欄の下端の 600 px まで広がった。

### 書体

| 要素 | 注入の前 | 部分ごとの規則 | メッセージの中のすべての要素への規則 |
| --- | --- | --- | --- |
| 名前 `span#author-name` | `Roboto, Arial, sans-serif` | `"Courier New"` | `"Courier New"` |
| 本文 `span#message` | 同上 | 同上 | 同上 |
| Super Chat の名前 `span#author-name` | 同上 | 同上 | 同上 |
| Super Chat の金額 `div#purchase-amount` | 同上 | 同上 | 同上 |
| Super Chat の本文 `div#message` | 同上 | 同上 | 同上 |

書体の指定は、以前の作りでも計算済みのスタイルには反映されていた。依頼者の決定にしたがい、書体の項目を「全体」の区画の 1 つにまとめ、メッセージの中のすべての要素とティッカーの中に当てる形にした。

## 確認していないこと

- 依頼者が選んだ書体と、画面での見え方。計算済みのスタイルは書体が変わったことを示すが、選んだ書体に日本語の文字が無ければ、日本語の文字は別の書体で表示される。
- ログインした状態の入力欄の背景。OBS のブラウザーソースは未ログインだった。
- モデレーターの発言、Super Chat、メンバーシップを含む実物のページでの背景の検査。実物のページには配信者の発言しか無かった。

## 考察

書体が変わらないという報告の原因は、選んだ書体に日本語の文字が無かったことだと推測します。計算済みのスタイルでは、以前の作りでも書体は当たっていたためです。依頼者に、選んだ書体を確かめたいと考えています。
