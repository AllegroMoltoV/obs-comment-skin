# Twitch の項目の実装

実施日: 2026-11-10
対象の課題: obs-comment-skin-dxs.19

## 結論

Twitch のチャットの項目の表、CSS の生成、プレビューの見本のページを作り、ドックでチャットの種類によって項目の表とプレビューを切り替えるようにした。ポータブル版 OBS で、ドックから作った Twitch のチャットのソースに文字の大きさを適用し、プレビューと実物のページの両方に反映されることを確かめた。

## 作成したもの

| ファイル | 内容 |
| --- | --- |
| `src/core/twitch-style.h`、`.cpp` | Twitch の CSS の生成 |
| `src/core/style-schema.cpp` | Twitch の項目の表 `twitch_sections()` を足した |
| `src/core/css-builder.h` | 値の読み取り、CSS の組み立て、縁取り、アニメーションの、YouTube と Twitch で共通の部品。YouTube の生成から切り出した |
| `src/core/chat-style.h` | チャットの種類ごとに項目の表と生成を選ぶ |
| `data/preview/twitch.html` | Twitch のプレビューの見本のページ。種別のバッジは data: の画像にし、alt で種別を表す |
| `src/source-state.cpp`、`src/preset-store.cpp` | 設定をチャットの種類ごとに保存する。プリセットに Twitch を足した |
| `src/comment-skin-dock.cpp`、`src/preview-panel.cpp` | 種類によって項目の表とプレビューの見本のページを切り替える |

### 項目

| 区画 | 項目 |
| --- | --- |
| 全体 | 書体 |
| メッセージ | 文字の大きさ、行の高さ、字間、文字の色、名前とコメント文の間に改行を入れる |
| 名前 | 文字の大きさ、Twitch の名前の色を使う、文字の色、配信者・モデレーター・VIP・サブスクライバーの色、バッジを表示する、名前の後に「:」を表示する |
| 文字の縁取り | YouTube と同じ |
| 背景 | 全体の背景色と不透明度、メッセージの背景色、配信者・モデレーター・VIP・サブスクライバーの背景色、メッセージの背景の不透明度と形 |
| サブスクの通知 | 文字の大きさ、文字の色 |
| 表示する部分 | 上部の見出し、下部の入力欄、チャットルームの案内 |
| アニメーション | YouTube と同じ |

共通の項目は YouTube と同じキーにした。「文字の色」は「Twitch の名前の色を使う」をオフにしたときだけ効く。種別ごとの色は、利用者ごとの色と全体の色より優先する。種別は、依頼者の決定にしたがい、バッジの画像の ID か alt の文字列のどちらかで見分ける。モデレーターの ID は観測で確かめたもので、配信者と VIP の ID は観測できていない候補である。

## 検証方法

- 単体テストで、空の設定で何も生成しないこと、すべての項目に値を入れても `@import` と `url(` を生成しないこと、名前の色の優先の順、表示する部分の規則、広告の iframe を隠さないことを確かめた。
- ポータブル版 OBS で、ドックの新規作成のダイアログから Twitch のチャットのソースを作り、ドックを UI Automation で操作した。プレビューと実物のページは CDP で読んだ。

## 検証結果

| 確認した内容 | 結果 |
| --- | --- |
| 新規作成のダイアログで Twitch を選び、チャンネル名を入力して作成 | 「Twitch チャット」が作られ、「URL から Twitch と判別しました。」と表示された。ドックは Twitch の項目の表に切り替わった |
| メッセージの文字の大きさを 24 px にする | プレビューと実物のページの両方で、本文が `font-size: 24px`、`line-height: 37.68px` になった。プレビューの資源の読み込みは 0 件だった |
| 種別のセレクターの一致 | プレビューでは配信者・モデレーター・VIP・サブスクライバーが 1 件ずつ。実物のページでは、読み込み直した直後の 1 行がサブスクライバーに一致した |
| 名前の後の「: 」のセレクター | プレビューと実物のページの両方で「: 」の要素に一致した |
| 利用者ごとの色の上書き | 名前に `color: rgb(1, 2, 3) !important` を当てると、インラインの色が上書きされた |

単体テストは成功し、ビルドの警告は 0 件だった。

## 確認していないこと

- 配信者と VIP の実物での色分け。配信者はユーザーテスト d で、依頼者の配信のチャットで確かめる。
- 色のダイアログでの操作と、Twitch のプリセットの保存と読み込み。
- 見た目の崩れの検査と設定の漏れの点検。課題 .20 で行う。
