# Twitch の崩れの検査と設定の漏れの点検

実施日: 2026-11-10
対象の課題: obs-comment-skin-dxs.20

## 結論

Twitch の項目を最大と最小にした CSS を、プレビューの見本のページと実物のページに当てても、崩れは 0 件だった。Twitch の項目の表を表示したドックの崩れも 0 件だった。

全体の背景を透明にしたとき、上部のランキング、下部の告知のカード、入力欄と送信ボタンが塗られたまま残った。このうちランキングには、隠す設定も背景の設定も無い。ランキングに隠す設定を足すかどうかは、隠す範囲の線引きにかかわるため、依頼者の判断に回す。

## 検証方法

見た目の崩れの検査は `docs/reports/2026-11-10-layout-check.md` の道具を Twitch に広げて行った。

- `tests/css-dump.cpp` に、チャットの種類を選ぶ 2 つ目の引数を足した。`comment-skin-css-dump max twitch` で Twitch の CSS を書き出せる。
- `tools/layout-check/page-check.mjs` の検査の対象に、Twitch のメッセージの行 `.chat-line__message` とサブスクの通知の行 `[data-test-selector="user-notice-line"]` を足した。文字の要素として、本文 `[data-a-target="chat-line-message-body"]` と名前 `.chat-author__display-name` を調べる。
- `tools/layout-check/opaque-scan.mjs` の出力に、生成された名前ではないクラスと `data-a-target` を足した。Twitch の要素には id が無く、タグ名だけでは見分けられないためである。

ページの検査は、ポータブル版 OBS 33.0.1 を CDP を有効にして起動し、ドックで「Twitch チャット」のソースを選んだ状態で行った。ソースの大きさは 400x600 である。

## 検証結果

### ページの崩れ

| ページ | CSS なし | 最大 | 最小 |
| --- | --- | --- | --- |
| Twitch のプレビュー | 14 要素、崩れ 0 件 | 14 要素、崩れ 0 件 | 14 要素、崩れ 0 件 |
| 実物の Twitch のページ | 18 要素、崩れ 0 件 | 18 要素、崩れ 0 件 | 18 要素、崩れ 0 件 |

検査が Twitch の要素の崩れを検知できることを確かめるため、行の高さを文字より小さくし、本文を 1 行の高さで切り取る CSS をプレビューに当てた。崩れは 21 件と報告された。内訳は、行の高さが文字より小さいものが 7 件、本文が祖先に切り取られたものが 7 件、名前が切り取られたものが 7 件である。

### ドックの崩れ

`pwsh tools/layout-check/dock-check.ps1 -ProcessId 17344` で、区画をすべて開いてスクロールしながら 93 個の部品を調べた。右端からのはみ出し、重なり、幅の不足は 0 件だった。検査の時点で、ドックのチャットの種類の欄は Twitch で、名前の区画に「Twitch の名前の色を使う」が表示されていたことを UI Automation で確かめた。

### 背景を透明にしたときに塗られて残る要素

全体の背景の不透明度を 0 にしたときに生成器が出力する規則と同じ CSS を、実物のページに当てた。

```css
html, body { background-color: transparent !important; }
.chat-room, .stream-chat-header { background-color: rgba(24, 24, 27, 0) !important; }
```

塗られたまま残った要素は次のとおりである。

| 要素 | 位置 | 背景色 | 扱い |
| --- | --- | --- | --- |
| 上部のランキング (トップ Cheer ユーザーランキング) | 見出しの直下。チャットの行に重なる | `rgb(24, 24, 27)` | 設定が無い。依頼者の判断に回す |
| 告知のカード (`chat-private-callout-queue` の中の `article`) | 入力欄の直上 | `rgb(69, 16, 147)` | Twitch の告知のため、線引きにしたがい隠す設定を置かない |
| 入力欄 (`chat-wysiwyg-input-box`) と送信ボタン、チャンネルポイントの表示 | 下部 | `rgb(24, 24, 27)` ほか | 「下部の入力欄」の設定で隠せる。表示する場合は入力欄としての見た目を保つ |

ランキングの要素は `[class*="channelLeaderboardHeader"]` で見つかった。ランキングから `.chat-room__content` へたどると、ランキングだけを含む `.tw-transition-group` があった。この要素を指定すれば、同じ場所に出るほかの要素を巻き込まずにランキングだけを隠せる。クラス名の末尾の `--MXQ0V` は生成された文字列のため、前方の一致で指定する必要がある。

Twitch の項目の表には、他の設定を選ばないと効かない項目に、YouTube と同じく灰色にする条件が付いていた。対象は、名前の文字の色、縁取りの幅と色、メッセージの背景の形、アニメーションの項目である。

## 考察

ランキングは、YouTube の上部に並ぶ Super Chat のアイコンと同じく、配信の画面ではチャットの行を覆う要素だと考えています。YouTube のアイコンには隠す設定を置いたため、ランキングにも同じ扱いが自然だと考えています。

告知のカードは利用者が閉じられる告知であり、隠す設定を置かない範囲に当たると判断しています。

## 確認していないこと

- 配信者と VIP の実物での色分け。ユーザーテスト d で確かめる。
- Bits の応援、強調表示、告知の行のときの崩れ。観測できなかった。
- ランキングを隠す CSS の実物での確認。依頼者の判断の後に行う。
