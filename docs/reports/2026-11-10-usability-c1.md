# ユーザーテスト c1

実施日: 2026-11-10
対象の課題: obs-comment-skin-dxs.8

## はじめに

全項目を作る前に、操作で迷う箇所と分かりにくい言葉を見つけるためのテストです。合否は判定しません。依頼者が、初めて使う配信者の立場で操作しました。

## 検証方法

手順書と記録用紙は `.prompts/MANUALS/2026111002-usability-c1.md` です。手順書には達成する目的だけを書き、操作の方法は書いていません。環境は、ポータブル版 OBS 33.0.1 に、コミット `YouTube の文字の大きさと色、背景色と不透明度の項目を足す` の時点のプラグインを入れたものです。

| 番号 | 達成する目的 |
| --- | --- |
| 1 | コメント欄の着せ替えのドックを開く |
| 2 | ライブ配信中の YouTube のチャットを表示するブラウザーソースを作る |
| 3 | チャットの文字を大きくし、背景を半透明の黒にして、OBS の画面で確かめる |
| 4 | 3 の変更を取り消し、YouTube の元の見た目に戻す |

## 検証結果

依頼者は会話で次のように報告しました。

> すべて問題なく動作しましたが、適用ボタンを押すまで反映されないところだけ、直感的に戸惑いました。

この報告から読み取れる結果は次のとおりです。

| 項目 | 結果 |
| --- | --- |
| 課題 1 から 4 の達成 | 4 つとも達成した。補助は求められなかった |
| 迷った箇所 | 設定を変えても、適用ボタンを押すまで画面に反映されないこと |
| 分かりにくい言葉 | 報告なし |
| 満足度 | 報告なし |

課題ごとの満足度と、課題ごとの迷った箇所の内訳は記録していません。

## 考察

設定を変えた時点で画面が変わると期待した操作に対し、実際は適用ボタンを押すまで変わらないため、戸惑いが生じたと考えています。適用を自動にしない現在の設計は、`.prompts/INIT.md` の 6.1 の要件によるものです。適用のたびにチャットが読み込み直され、表示中のコメントが消えるためです。対応の方法は、この要件との関係で依頼者に判断を仰ぎます。
